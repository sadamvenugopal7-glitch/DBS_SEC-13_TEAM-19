MySQL Workbench & CLI Import Instructions

Follow these standard commands to import the complete project database into MySQL 8.x

Command Prompt / PowerShell:
# 1. Log in to MySQL CLI
mysql -u root -p

# 2. Source the complete database script
SOURCE C:/path/to/wines-management-system/database/complete_database.sql;
Always use forward slashes (/) in the MySQL SOURCE file path.
MySQL Workbench Graphical Tool:
  1. Open MySQL Workbench and connect to your local instance.
  2. Navigate to File → Open SQL Script... (or press Ctrl+Shift+O).
  3. Select database/complete_database.sql from this project folder.
  4. Click the Execute (Lightning Bolt) button to initialize all tables, seed data, views, and triggers.
